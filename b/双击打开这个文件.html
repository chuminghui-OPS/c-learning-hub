电子扫盲

解决最基础的电脑使用问题：能读资料、管文件、装软件、搜问题，并用 AI 自行排查大部分入门问题。后续课程以文档自学、独立操作和现场答疑为主。

前置条件清单

  • 一台可登录的 Windows 10/11 电脑（管理员权限可用）。
  • 能接入互联网；已安装 Edge 或 Chrome。
  • 一个可用邮箱 / B 站账号（看视频、后续注册开发工具用）。
  • 本页建议在电脑上打开，不要只在手机上看。

1 · 电脑与系统基础

先分清「谁在干活」：CPU 算，内存暂存，硬盘长期存，GPU 画图。系统卡顿优先怀疑内存占用和后台进程，不是先重装系统。

操作系统

操作系统（OS）是设备的基础软件，负责连接你、应用程序和硬件。通过它可以开机、联网、装软件、管文件、连打印机或 U 盘。

系统用在哪一句话
Windows多数个人电脑兼容性最好，学校/办公/游戏常见
macOS苹果 Mac和 iPhone/iPad 配合好；部分 Windows 软件不能直接跑。犹豫要不要买 Mac，多半不适合
Linux服务器、开发开源、可定制；发行版多，初学有适应期
鸿蒙华为多设备多端协同；工科很多软件不适配，极其不推荐当主力学习机
Android / iOS / iPadOS手机平板点按滑动为主；应用商店安装

重点掌握日常使用，不需要底层原理。电视、手表、路由器也有专用系统，很多基于 Linux。

1.3 Windows 基本操作 · 桌面 · 开始菜单 · 任务栏 · 通知区域

  1. 按 Win，输入「记事本」

    预期反馈：开始菜单弹出搜索结果，首选出现「记事本」应用。回车即可打开。

  2. 在任务栏右键记事本图标 →「固定到任务栏」

    预期反馈：图标常驻任务栏，关闭程序后图标仍在，点击可再次启动。

  3. 点任务栏最右侧「^」展开托盘，找到音量与网络

    预期反馈：能看到当前 Wi-Fi 名称与音量滑条。这是排查「没声音 / 没网」的第一现场。

1.4 程序与窗口

  • 最小化：程序仍在运行，只是藏到任务栏。
  • 关闭（×）：结束该程序。部分软件点 × 只是缩小到托盘，要看托盘图标。
  • 切换：Alt+Tab 按住 Alt 连续点 Tab；或点任务栏图标。
  • 分屏：把窗口拖到屏幕左/右边缘，自动占半屏；Win+← / Win+→ 同效。
  • 强制结束：见下文任务管理器，不要长按电源键。

按键作用何时用

1.6 任务管理器

用途：看谁在占资源、杀掉卡死程序、禁用开机自启。打开方式优先 Ctrl+Shift+Esc。

  1. 按 Ctrl+Shift+Esc

    预期反馈：任务管理器窗口直接弹出，不需要经过 Ctrl+Alt+Del 屏幕。

  2. 点「进程」页签 → 按「内存」列排序

    预期反馈：占用最高的程序排到最上面。浏览器开一堆标签时通常排第一。

  3. 选中卡死的程序 → 点「结束任务」

    预期反馈：该程序窗口消失。若桌面图标/任务栏也消失，在任务管理器「文件 → 运行新任务」输入 explorer 回车。

  4. 切到「启动应用」→ 对无关软件右键「禁用」

    预期反馈：状态变为「已禁用」。下次开机该软件不再自动常驻。保留：杀毒、显卡驱动、输入法。

1.7 常见系统设置

入口：点任务栏右下角音量/网络图标可直达；完整设置用 Win+I。

  • 音量：托盘喇叭 → 滑条；应用单独音量在「音量合成器」。
  • 网络：托盘 Wi-Fi → 选网 → 连接；能打开网页才算通。
  • 显示：设置 → 系统 → 显示 → 缩放（笔记本高分屏常调到 125%/150%）。
  • 输入法：托盘「中/英」或 Win+空格 切换。
  • 默认打开方式：右键文件 →「打开方式 → 选择其他应用」→ 勾选「始终使用」。

描述问题的最低标准

禁止只说「电脑坏了」。提问必须包含：① 现象原文（截图/报错文字）② 操作系统版本 ③ 软件名与版本 ④ 已做过的步骤 ⑤ 何时开始出现。做不到这五点，别人无法帮你。

1.8 电源与性能

场景设置操作路径
日常学习 / 插电写代码平衡或最佳能效设置 → 系统 → 电源
宿舍熄灯用电池最佳能效 + 降低屏幕亮度同上；托盘电池图标
游戏 / 视频渲染 / 大型编译最佳性能；确认独显参与电源模式 + 显卡控制面板 / 设置 → 显示 → 显示卡
后台静默吃电禁用无用启动项与后台应用任务管理器 → 启动应用

日常学习用省电/能效模式，关掉不需要的后台。游戏或高性能任务再切性能模式，并了解帧率限制（限制帧率能降功耗和发热）。独显可按应用指定走核显或独显。

2 · 文件与文件夹管理

本部分是整门课最需要落地的内容。目录结构不对，后面提交作业、装环境、迁移电脑都会反复翻车。

2.2 基础操作原子步骤

  1. 按 Win+E → 进入 D 盘（若无 D 盘用「文档」）

    预期反馈：资源管理器打开，左侧可见此电脑各分区。

  2. 右键空白处 → 新建 → 文件夹 → 命名 Study

    预期反馈：出现名为 Study 的文件夹。后续所有社团资料进这里。

  3. 进入磁盘后新建 Study → 再建 C、Tools、Projects、Screenshots

    预期反馈：资源管理器显示四个子文件夹。

  4. 选中文件 → Ctrl+C → 点目标文件夹 → Ctrl+V

    预期反馈：源文件仍在，目标多出一份 = 复制成功。

  5. 改用 Ctrl+X 再粘贴

    预期反馈：源位置文件消失，目标位置出现 = 移动成功。

  6. 按 F2 重命名；按 Delete 移入回收站

    预期反馈：名称进入编辑态；删除后可在回收站还原（未清空前）。不要删除自己不认识的系统文件或软件安装目录里的文件。

  7. 资源管理器右上角搜索框输入 hello.c

    预期反馈：当前文件夹及子目录中出现匹配文件。点「打开文件所在位置」可跳转。

2.3 文件后缀名

后缀名决定「系统用什么程序打开它」。文件名是给人看的，后缀名是给系统看的。

▶ 点击加载 · 文件在哪(中) · 扩展名
必看 · 文件在哪(中)【大学生Windows基础03】路径丨扩展名丨打开文件夹

立刻显示后缀名（Win10/11）

资源管理器顶部「查看 → 显示 → 文件扩展名」勾上。看不到 .txt / .c 就无法判断文件类型，后面踩坑概率翻倍。

后缀类型谁打开用途
.c / .hC 源码 / 头文件编辑器 / IDE阅读、修改、提交
.md / .pdf / .docx文档编辑器 / 阅读器 / Word笔记、教程、作业
.txt纯文本记事本便签、日志
.zip / .rar / .7z压缩包7-Zip / Bandizip打包传输
.exe / .msi可执行 / 安装包系统运行安装或启动软件 —— 来源必须可信
.png / .jpg图片照片查看器截图、素材
.lnk快捷方式系统只是入口，删掉一般不删原程序

规则：把 作业.c 改名成 作业.c.txt 后，它就变成文本文件；把 病毒.txt 改成 病毒.exe 也不会变成正常安装包——改后缀只是换了标签，双击会报错或被拦截。改后缀 ≠ 改内容；来源不明的文件不要为了「试试看」去改后缀。

2.4 压缩与解压

课堂练习用压缩包由社团群文件在课后发放，文件名含 电子扫盲；下载后解压到 Study\C\Homework\ 再操作。

压缩包是单个文件，不是文件夹。双击只能预览，交作业、装软件前通常要解压到明确路径。

推荐工具 7-Zip 官网 Bandizip

  1. 安装 7-Zip 或 Bandizip 后，右键 xxx.zip

    预期反馈：右键菜单出现「7-Zip / 解压到当前文件夹 / 解压到 xxx\\"」。

  2. 优先选「解压到 xxx\\」（解压进同名文件夹）

    预期反馈：多出一个与压缩包同名的文件夹，文件不会撒满桌面。

  3. 打开解压后的文件夹，确认文件完整

    预期反馈：能看到真正的源码/文档，而不是还有一层压缩包。

  4. 要发送目录时：右键文件夹 → 7-Zip → 添加到「xxx.zip」

    预期反馈：生成同名 zip。注意不要把 node_modules、虚拟环境等巨大目录打进去。

2.5 管理下载内容

  1. 在浏览器菜单里打开「下载」页（下载记录）

    预期反馈：列出最近下载文件；点文件夹图标可直接跳到下载目录。

  2. 下载完成后立即：确认文件名完整、后缀正确、体积合理

    预期反馈：若是 xxx.exe 且体积异常小（几百 KB 却号称完整安装包），大概率是「下崽器」，删除。

  3. 把有用文件移动到 Study\... 对应子目录

    预期反馈：下载文件夹里只剩垃圾可定期清空。

下载文件夹不是仓库

允许下载文件夹短期中转，禁止长期堆积。每周清一次：有用的移走，无用的删除。桌面同理。

统一学习目录

为什么学：这是最重要的一段之一。后面代码、课件、作业、工具都要有固定位置。

建议结构：

Study/
├── C/
│   ├── 课件/
│   ├── PDF/
│   └── Homework/
├── Tools/
├── Projects/
└── Screenshots/
  • 课件、作业、练习代码、开发工具、项目、截图分类存放。
  • 名称尽量用英文 / 数字 / 下划线 / 连字符；安装路径绝对不要中文。
  • 文件名要能看出内容，例如 week01_hello.c，不要「新建文本文档.c」「作业最终版真的最终版.c」。
  • 已在数据盘（或「文档」）建立 Study 根目录
  • 已建 Study 及 C / Tools / Projects / Screenshots
  • 资源管理器已开启「文件扩展名」显示
  • 已安装 7-Zip 或 Bandizip，并能右键解压
  • 本周下载文件夹已清空或迁移完毕

3 · 浏览器与网络资料

后续学习依赖大量官网、文档、博客。目标不是「会打开百度」，而是用关键词拿到正确版本的正确文件。

浏览器基本使用

搜索引擎：少用百度

百度结果里广告、采集站、过时内容多。技术问题优先用 Bing、官方文档和社区资料。

建议用 Edge：第一步先改默认搜索引擎（可搜「Edge 修改默认搜索引擎」跟做）。很多官网很难找，可直接问豆包：「给我 xxx 软件的官网」——小心「steam 游戏管家 / 游戏中心」这类仿冒名。

  1. 地址栏既可以输网址，也可以输关键词

    预期反馈：输 https://www.7-zip.org 直达官网；输 7-zip 官网 下载 进入搜索结果。

  2. 标签页：中键点击链接 = 后台新开；Ctrl+W 关闭；Ctrl+Shift+T 恢复误关

    预期反馈：阅读资料时不丢当前页面。

  3. 对长期使用的站点：地址栏右侧☆ → 添加书签（或 Ctrl+D）

    预期反馈：书签栏出现该站。建议建「学习」文件夹归类。

关键词公式

模糊说法（无效）可执行关键词（有效）
为什么不能用Visual Studio Code 1.92 扩展宿主进程意外终止 Windows 11
电脑好卡Windows 11 内存占用高 任务管理器 System 占用
下个编译器MinGW-w64 官网 下载 Windows x86_64
解压打不开zip 解压 CRC 错误 7-Zip 如何修复

拆词原则：软件名 + 版本 + 系统 + 具体现象/报错原文。报错信息直接整段搜索，比用中文转述准。必要时改用英文关键词再搜一遍。

阅读技术文档

  • .md：装一个 Markdown 阅读器（如 Obsidian 或 VS Code）。
  • .pdf：Edge/Chrome 直接拖入即可。
  • 官方文档结构：先看 Quick Start / Install，再看你实际用的 API，不要从第一页死磕。

优先级来源用法

2GitHub 官方仓库 Release开源工具的可信安装包
3学校/社团统一文档版本与路径以社团为准，优先于网上教程

浏览器说「已阻止」怎么办？

  1. 先别点「保留」。
  2. 回忆：是不是从官网或社团链接下的？是 → 保留；不确定 → 删掉重下。

Steam++ 与 GitHub

Watt Toolkit（Steam++）：一类网络工具，可改善部分平台/服务的访问体验。

  • 不要乱装「不明加速器」；用社团已验证的工具或问学长。

4 · 软件安装与环境配置

安装翻车的两个根因：下载了假安装包，以及无脑点下一步。

下载 · 安装 · 运行

类型特征正确做法
官方安装包 .exe/.msi体积与官网标称接近，有数字签名运行安装；看清每一步勾选

安装路径与配置意识

  1. 从社团文档 / 官网 / GitHub Releases 下载指定版本安装包到 Study\Tools\

    预期反馈：安装包出现在 tools 目录，文件名含版本号，体积合理。

  2. 右键安装包 →「以管理员身份运行」（仅当需要写系统目录时）

    预期反馈：出现 UAC 提示，确认来源后再点「是」。

  3. 每一页都读：协议跳过即可，但「附加软件/推荐组件」全部取消勾选

    预期反馈：安装摘要里只剩目标软件本身。

  4. 路径改为 Study\Tools\<软件名>\（无中文、无空格）

    预期反馈：路径输入框显示英文路径。若程序强制装 C 盘且社团未指定，保持默认并记录。

  5. 安装完成后：开始菜单搜索软件名 → 右键「打开文件所在位置」确认快捷方式

    预期反馈：能定位到安装目录；桌面出现快捷方式（可选）。

▶ 点击加载 · 安装与卸载
必看 · 安装与卸载【大学生Windows基础08】快捷方式丨正确卸载

卸载规则

用「设置 → 应用 → 安装的应用 → 卸载」，或软件自带 Uninstall。不要直接删安装文件夹（会残留服务、注册表、右键菜单）。卸载后重启资源管理器或注销，残留图标才会消失。

5 · 拥抱 AI

入门用豆包、DeepSeek 等聊天 AI 就够了。AI 能帮你查问题，但不能全信。

怎么问 AI

【环境】我使用 Windows 11，安装 XXX 软件时出现 XXX 报错
【目标】右键 zip 时出现「7-Zip → 解压到当前文件夹」
【现象】右键菜单里完全没有 7-Zip 一项；双击 zip 用的是系统自带预览
【已做】已从 7-zip.org 安装；已重启过一次资源管理器
【要什么】先解释右键菜单是怎么来的，再给 3 步以内的排查，不要让我重装系统

  1. 把报错截图或全文贴进去

    预期反馈：AI 能引用具体错误码/路径，而不是泛泛而谈。

  2. 明确「先解释原因，再给步骤」

    预期反馈：回答结构是原理 → 操作 → 验证，而不是直接甩一段脚本。

  3. 按步骤执行，并把真实结果贴回去继续追问

    预期反馈：第二轮回答能针对你的输出收敛，而不是重复第一轮。

AI 说的不一定对

  • AI 让你关杀毒、删系统文件、乱改注册表 → 别做，先问学长。
  • AI 给的下载链接先看域名是不是官网。
  • 看不懂的命令不要硬跑，先让 AI 解释清楚。

以后再用命令行 AI

先把上面基础打牢。以后会用资源管理器找文件了，再接触 Codex 这类工具。

  • 它们能读项目、改代码、解释报错，但会直接改你电脑里的文件。
  • 第一次用：在空文件夹里试，别对着唯一作业跑。
  • 先会看它改了什么，再让它改。

课后验收（全部做完才算过关）

  • 能用 Ctrl+Shift+Esc 结束一个故意卡住的程序（如未响应的记事本）。
  • 已禁用至少 1 个无用启动项。
  • 已按「统一学习目录」建好 Study 结构。
  • 已开启文件扩展名显示；能说出 .c/.md/.zip/.exe 各自用途。
  • 从 7-Zip 官网下载并安装，练习右键解压一个 zip。
  • 用关键词搜到某软件官网，核对域名后完成下载。
  • 按 5.1 模板向 AI 提一个真实问题，并根据回答完成一次排查。

三个常见坑（遇到先看这里）

坑 1 · 压缩包打不开里面的文件

双击 zip 只是预览，文件并没有真正解压出来。

关掉预览窗口 → 在 zip 上右键 → 选「解压到当前文件夹」或「解压到 xxx\\」→ 打开解压出来的那个文件夹再用。

坑 2 · 装完软件，桌面多了一堆垃圾

多半是安装时没取消勾选，或者下错了「下载器」。

设置 → 应用 → 按安装日期排序 → 卸载今天多出来的软件 → 任务管理器「启动应用」里把残留项禁用 → 回官网重下。

坑 3 · 问别人问题，对方帮不上

只发一句「跑不起来」，别人没法帮你。

用 Win+Shift+S 截图，附上：什么系统、什么软件、完整报错原文、你已经试过什么。
